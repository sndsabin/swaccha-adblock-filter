Manual Installation

  • Navigate to brave://adblock.
  • Paste the raw URL into Add custom filter lists box.
  • Click Add.
  • Open the uBlock Origin settings dashboard.
  • Navigate to the Filter lists tab.
  • Scroll to the bottom, check Import...
  • Paste the raw URL and click Apply changes.
  • Open AdGuard Settings → Filters → Custom.
  • Click Add custom filter.
  • Paste the URL and click Next.
  • Click the Adblock extension icon and open Options.
  • Select Filter Lists from the left menu.
  • Click Add a custom filter list.
  • Paste the raw URL and click Add It.
  • Click the Adblock Plus icon and open Options (gear icon).
  • Go to the Advanced tab.
  • Under FILTER LISTS, click ADD FILTERS VIA URL.
  • Paste the raw URL and click ADD A FILTER LIST.
